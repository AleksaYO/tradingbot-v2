# Чеклист готовности бота к запуску

## ⚠️ ВАЖНО: Перед запуском в LIVE режиме

### 1. ✅ Безопасность (КРИТИЧНО!)

- [ ] **DRY_RUN=true** по умолчанию - бот запустится в тестовом режиме
- [ ] Для LIVE торговли нужно явно установить `DRY_RUN=false` в `.env`
- [ ] API ключи должны иметь **только права на торговлю фьючерсами**
- [ ] **НЕ используйте** API ключи с правами на вывод средств
- [ ] Рекомендуется создать отдельный API ключ только для бота

### 2. ✅ Конфигурация

- [ ] Создан файл `.env` на основе `env.example`
- [ ] Установлены реальные API ключи (для live режима)
- [ ] Проверены параметры риска:
  - `MAX_DAILY_LOSS` - максимальный убыток за день (USD)
  - `MAX_POSITION_SIZE` - максимальный размер позиции
  - `STOP_LOSS_PERCENT` - процент стоп-лосса
  - `TAKE_PROFIT_PERCENT` - процент тейк-профита
- [ ] Установлен правильный `SYMBOL` (например, BTCUSDT)
- [ ] Установлен `LEVERAGE` (рекомендуется начать с 1-5x для тестирования)

### 3. ✅ Зависимости

- [ ] Установлены все зависимости: `npm install`
- [ ] Проект скомпилирован: `npm run build`
- [ ] Нет ошибок компиляции

### 4. ✅ Тестирование

- [ ] **ОБЯЗАТЕЛЬНО** протестировать в DRY_RUN режиме минимум 1-2 дня
- [ ] Проверить работу WebSocket подключения
- [ ] Проверить генерацию сигналов
- [ ] Проверить логирование
- [ ] Проверить обработку ошибок

### 5. ✅ Мониторинг

- [ ] Настроено логирование (файл `logs/tradingbot.log`)
- [ ] Есть способ мониторить работу бота
- [ ] Понимание как остановить бота (Ctrl+C)

2. **Начните с минимальных сумм и параметров риска**
3. **Всегда тестируйте в DRY_RUN режиме перед live торговлей**

## 📋 Пошаговая инструкция запуска

### Шаг 1: Подготовка
```bash
# 1. Создайте .env файл
cp env.example .env

# 2. Отредактируйте .env и установите:
# - BINANCE_KEY=ваш_api_ключ
# - BINANCE_SECRET=ваш_секретный_ключ
# - DRY_RUN=true (для тестирования)
```

### Шаг 2: Установка зависимостей
```bash
npm install
```

### Шаг 3: Компиляция
```bash
npm run build
```

### Шаг 4: Тестовый запуск (DRY RUN)
```bash
# Убедитесь, что DRY_RUN=true в .env
npm run dev
# или
npm start
```

### Шаг 5: Мониторинг
- Следите за логами в консоли
- Проверяйте файл `logs/tradingbot.log`
- Убедитесь, что сигналы генерируются корректно

### Шаг 6: Переход в LIVE режим (только после тестирования!)
```bash
# В .env установите:
# DRY_RUN=false

# Запустите бота
npm start
```
